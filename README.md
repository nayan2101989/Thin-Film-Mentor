# Thin-Film Lab Mentor (offline edition)

Installable web app by Mehedi Hasan, EIT. Works offline after the first visit:
solar cell, photodetector and photoconductor calculators, J–V file analysis,
defect tables, photodetector parameters, the builder's recipe and a searchable
library of about 90 entries. "Ask the AI mentor" opens the live Claude version
(needs internet).

Library entries are summaries in the builder's own words; cite the original papers.

To update: replace index.html, and change `tf-mentor-v1` in sw.js to a new
version (v2, v3...) so installed phones download the new copy.
